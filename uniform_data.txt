// dfn.txt 为原始 DFN 裂缝网络文件。
// 该文件记录每一条天然裂缝的显式几何和物性。
// 与 DFN_PERMX、DFN_PERMY、DFN_PERMZ、DFN_PORO 不同，
// dfn.txt 描述的是原始裂缝面本身；

//
// dfn.txt 文件开头通常包括 FORMAT、PROPERTIES、SETS 等信息。
//
// BEGIN FORMAT 部分示例说明：
//     Format = Ascii
//         表示文件为 ASCII 文本格式。
//     Length_Unit = M
//         表示长度单位为 m。
//     XAxis = East
//         表示 X 轴方向为 East。
//     Scale = 1
//         表示坐标缩放系数为 1。
//     No_Fractures = 200
//         表示该 DFN 文件中共有 200 条天然裂缝。
//     No_Nodes = 831
//         表示所有裂缝顶点总数为 831。
//     No_Properties = 3
//         表示每条裂缝有 3 个属性。
//
// BEGIN PROPERTIES 部分说明每条裂缝属性列的含义：
//     Prop1 = Permeability
//         第 1 个属性为裂缝渗透率。
//     Prop2 = Compressibility
//         第 2 个属性为裂缝压缩系数。
//     Prop3 = Aperture
//         第 3 个属性为裂缝开度。
//
// BEGIN SETS 部分说明裂缝集合：
//     Set1 = "DFN1"
//         表示裂缝属于 DFN1 这个集合。
//
// BEGIN FRACTURE 部分为每条裂缝的具体数据。
// 每条裂缝的数据由三部分组成：
//
// 第一行：裂缝基本信息和属性
// 格式为：
//     fracture_id   vertex_number   set_id   permeability   compressibility   aperture
//
// 例如：
//     1    5    1    85.410107    3.40282e+38    0.000001
//
// 表示：
//     fracture_id = 1
//         第 1 条裂缝；
//     vertex_number = 5
//         该裂缝由 5 个顶点构成；
//     set_id = 1
//         该裂缝属于第 1 个裂缝集合，即 DFN1；
//     permeability = 85.410107
//         该裂缝的渗透率；
//     compressibility = 3.40282e+38
//         该裂缝的压缩系数属性。

//     aperture = 0.000001
//         该裂缝开度为 0.000001 m。
//
// 接下来的 vertex_number 行：裂缝顶点坐标
// 格式为：
//     vertex_id   x   y   z
//
// 例如：
//     1    435231.384647    6479495.376064    3050.473915
//     2    435305.338815    6479556.310052    3084.119533
//     3    435165.988460    6479437.019367    3031.791548
//     4    435329.971257    6479553.809348    3151.730146
//     5    435185.592704    6479424.935322    3110.575461
//
// 表示第 1 条裂缝有 5 个顶点，每个顶点给出 x、y、z 坐标。
// 这些顶点共同构成一个多边形裂缝面。
//
// 最后一行：裂缝面法向量
// 格式为：
//     0   normal_x   normal_y   normal_z
//
// 例如：
//     0    -0.682730    0.677434    0.273794
//
// 表示该裂缝面的单位法向量。
// 其中 normal_x、normal_y、normal_z 分别为法向量在 X、Y、Z 方向上的分量。
//
// 因此，dfn.txt 中每一条裂缝的完整结构为：
//     1 行裂缝编号、顶点数、集合编号和属性；
//     vertex_number 行顶点坐标；
//     1 行裂缝面法向量。
//
// 如果 vertex_number = 4，则该裂缝通常为四边形裂缝面；
// 如果 vertex_number = 5 或 6，则为五边形或六边形裂缝面。
//
